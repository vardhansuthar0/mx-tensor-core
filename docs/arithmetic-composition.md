# Compositional PE arithmetic refinement

The certificate is generated by `scripts/arithmetic_composition.py` only after every component campaign passes against the current source. The certificate's scope is the PE's independent 32-element dot specification, for all nine supported lane/pipeline configurations. Physical checks and coverage remain separate obligations. A missing or timed-out proof leaves the certificate unclosed.

## Transaction contract

An accepted input beat is `in_valid && in_ready`. A block contains `32/LANES` accepted beats. Its first beat supplies format, scales, output format and truncation; later metadata inputs may change freely. The reference accumulates all 32 signed quantized products, ORs special/approximation flags, then applies the independent integer quotient/remainder RNE converter in `formal/converter_spec.svh`. The complete independent dot function is `reference_dot` in `formal/arithmetic_reference.svh`.

The initial state requires synchronous reset. Later resets, bubbles, stalls and input changes are arbitrary. The claim uses two-state RTL semantics and supported LANES 8/16/32 and PIPE_STAGES 3/4/5. It does not establish array/APB equivalence or four-state X behavior.

## Proof boundaries

| Production region | Checked contract | Evidence |
| --- | --- | --- |
| Decoder and one-lane product cone | Independent fixed-point element magnitudes, signed product, truncation, NaN/infinity/approximation flags; every raw byte pair | product-exhaustive.json |
| Replicated product loop | N-lane outputs equal N independent copies of the certified lane cone, with flag OR; arbitrary decoded words | product-bindings.json, replication rows |
| Decode and product registers | Exact production register/reset/enable behavior at explicit decode/product oracle ports | product-bindings.json, register rows |
| CSA hierarchy | Every reduction bit is the exact XOR/majority reduction; each recursive child is smaller; base adder is modulo 2^70 | csa-composition.json |
| Block control and accumulation | Independent first-beat metadata and format selection, modulo sum/flags, pending-token conservation, packet/valid latency under stalls/resets | streaming-refinement.json |
| Normalization and packet/output registers | Independent absolute value and linear highest-bit reference; converter arguments, packet alignment and result capture/hold/reset | normalization-refinement.json |
| Scalar conversion | All signed 70-bit sums, 10-bit scales, output formats and flags equal the independent quotient/remainder RNE specification | converter-specification.json |

The decode-register cut replaces only the exact calls `decode(in_a[8*i+:8],active_fmt)` and the corresponding B calls with explicit symbolic 14-bit ports. The checker requires both production call sites for each operand. Its independent register state proves lane indexing, reset, bypass and capture. The numerical decoder itself is included verbatim in the exhaustive one-lane check. The streaming proof independently checks `active_fmt`, held first-beat format and all metadata.

The product-register cut replaces only the combinational product cone, whose lane replication is separately checked. Arbitrary product/flag input ports prove capture and stall behavior without duplicating multipliers across sequential time frames. These are universal contracts: substituting the certified real combinational functions for their oracle ports preserves the register proofs.

The streaming cut supplies arbitrary beat sums and special flags through the same number of enabled decode/product stages. The product-register and CSA contracts establish that the actual beat values satisfy this interface. Consequently, its independent accumulated packets equal the accepted real lane products and flags.

The normalization proof extracts the production network and registers. It replaces only the exact scalar converter call with an arbitrary 37-bit result, after requiring the full production argument list. It separately proves that the actual magnitude/leading arguments correspond to the packet's signed sum. Substituting the all-input scalar-conversion contract therefore connects the accumulated packet to the final rounded data/flags. The output-valid proof establishes transaction order and enabled-cycle latency; output data/flags are compared when valid and their register hold/reset behavior is also checked.

## Exact integer accumulation

The exhaustive product campaign includes 27,262,976 assignments: five supported formats with poison on/off, three reserved formats with required poison, all 256 A/B byte codes and all 32 truncations. Its reference grid table is independent of the RTL grid lookup. It also measures the maximum finite product and fails unless the observed maximum is exactly:

- one finite product: `49 * 2^58 = 14123288431433875456`;
- 32 product magnitudes: at most `49 * 2^63 = 451945229805884014592`;
- signed 70-bit positive boundary: `2^69 = 590295810358705651712`.

Truncation cannot increase magnitude. Every partial sum therefore fits in signed 70 bits. The CSA's modulo-2^70 contract and the streaming modulo accumulation are consequently exact integer sums for all reachable finite products. Poison and special values are handled by separately checked flags, rather than entering finite arithmetic.

For each 3:2 reduction, the checker compares every actual elaborated child-input bit to its exact Boolean polynomial. This establishes disjoint triples and untouched remainders, including discarded carry beyond bit 69. A separate SAT proof establishes the 70-bit compressor identity. Induction over strictly decreasing child widths establishes the full trees without a monolithic associative-adder SAT problem.

## Fail-closed evidence

Each component report records source hashes. The assembler checks every expected configuration and positive/negative row, all source hashes, the exhaustive input count/range, CSA controls and independent reference bindings. Its certificate binds the reports themselves as well as all proof generators. Six corrupted-report controls must be rejected before a pass certificate is written.

Deliberately incorrect output-valid, magnitude, products and CSA wiring properties must produce actual counterexamples or structural rejection. Timeout, missing output and tool failure do not count as negative-control success. The published certificate remains a compositional proof; it is not represented as a completed monolithic unroll.
